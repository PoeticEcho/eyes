# 🐾 나노바나나 동물 시각 탐험대

**나노바나나 동물 시각 탐험대**는 아이가 사람, 강아지, 뱀, 벌, 지렁이, 물고기의 감각 차이를 놀이처럼 체험하는 어린이 과학 웹 앱입니다.

배경과 아이콘을 하나의 Canvas에 함께 그리고, 그 결과를 동물별 시각·감각 필터로 변환합니다. 게임 모드에서는 움직이는 목표물을 찾고, 카메라 모드에서는 휴대폰 카메라 화면에 동물 눈 필터를 씌워 주변 세상을 탐험할 수 있습니다.

> 이 앱은 동물의 감각을 100% 재현하는 과학 장비가 아닙니다. 실제 생물학 원리를 어린이가 이해하기 쉽게 바꿔 보여주는 **교육용 시뮬레이션**입니다.

- 사람, 강아지, 뱀, 벌, 지렁이, 물고기 감각 체험
- 동물별 **오늘의 생존 미션**
- 결과 화면의 **보호자 질문 카드**
- Canvas 기반 800×600 고정 해상도 렌더링
- 배경과 아이템을 한 캔버스에 합성한 뒤 동물별 필터 적용
- 움직이는 목표물과 방해물, 벽 반사 기반 간단한 물리 엔진
- 글을 모르는 아이도 이해할 수 있는 미션 보드
- 라이브 카메라 모드
- 뱀 카메라 모드의 AI 온기 실험 기능
- 사람 눈 ↔ 동물 눈 비교 모드
- 전체화면 토글
- 정답/오답 효과음, 진동, 파티클 피드백
- 한국어 음성 안내
- 저성능 모드와 자동 품질 조절
- 카메라 사전 동의 모달
- 개인정보 안내
- 보호자 설정

| 🐶 강아지 | 색보다 냄새 입자와 움직임 단서를 따라 공을 찾아요 | 적록 구분 약화, 냄새 단서 강조 |

| 🐝 벌 | 꽃의 숨은 UV 길잡이를 따라 꽃을 찾아요 | 겹눈 모자이크, UV 넥타 가이드 비유 |
| 🐛 지렁이 | 밝은 곳을 피해 촉촉한 낙엽을 찾아요 | 어두운 화면, 진동·습기·빛 변화 단서 |
| 🐠 물고기 | 둥근 물 위 창 안에 모여 보이는 목표물을 찾아요 | 스넬의 창, 어안 왜곡, 수면 경계 효과 |

## 과학적 주의점

이 앱은 어린이용 교육 시뮬레이션이므로 실제 생물 감각을 단순화합니다.

| 동물 | 주의할 점 |
|---|---|
| 👦 사람 | 사람 눈이 모든 생물의 기준은 아닙니다. |
| 🐶 강아지 | 강아지가 세상을 흑백으로만 보는 것은 아닙니다. 빨강·초록 구분이 약하고, 냄새와 움직임 단서도 중요합니다. |
| 🐍 뱀 | 모든 뱀이 열을 감지하는 것은 아닙니다. 일부 뱀은 피트 기관으로 열 차이를 감지합니다. 앱의 열화상은 실제 체온 측정이 아닙니다. |
| 🐝 벌 | 화면의 보라색은 진짜 자외선이 아니라, 벌이 볼 수 있는 숨은 꽃 무늬를 표현한 교육용 약속 색입니다. |
| 🐛 지렁이 | 파동 효과는 지렁이가 귀로 소리를 듣는다는 뜻이 아닙니다. 빛 변화, 습기, 진동 같은 비시각 단서를 비유한 표현입니다. |
| 🐠 물고기 | 스넬의 창은 물고기 눈 자체의 렌즈 효과라기보다 물과 공기 경계에서 빛이 굴절되어 생기는 현상입니다. |

## AI 온기 모드

AI 온기 모드는 카메라의 **뱀 모드**에서 사용할 수 있는 실험 기능입니다.

```text
카메라 프레임
→ TensorFlow.js COCO-SSD 객체 탐지
→ person / dog / cat 만 통과
→ 최대 3개까지 따뜻한 온기 덩어리로 표시
→ 나머지 배경은 차가운 파랑 계열로 표시
```

중요한 점:

- 일반 휴대폰 카메라는 실제 적외선 열을 직접 볼 수 없습니다.
- 이 기능은 실제 체온 측정이 아닙니다.
- AI가 사람·강아지·고양이처럼 보이는 영역을 찾아 따뜻하게 칠하는 교육용 표현입니다.
- 손, 발, 얼굴을 별도로 탐지하지 않습니다.
- 카메라 영상 자체는 서버로 전송하지 않고 브라우저 안에서만 처리합니다.
- 단, AI 모델을 처음 사용할 때 TensorFlow.js와 COCO-SSD 스크립트를 CDN에서 내려받습니다.

## 실행 방법

### 1. 로컬에서 바로 열기

파일을 더블 클릭해서 열 수 있습니다.

```text
index.html
```

다만 휴대폰에서 `file://` 또는 `content://media/external/file/...` 형태로 직접 열면 카메라, 전체화면, 외부 AI 모델 로딩이 제한될 수 있습니다.

### 2. 로컬 서버 실행

개발 중에는 정적 서버 사용을 권장합니다.

```bash
python3 -m http.server 8080
```

브라우저에서 접속합니다.

```text
http://localhost:8080
```

### 3. 실제 배포

카메라 기능과 AI 모델 로딩을 안정적으로 사용하려면 HTTPS 배포를 권장합니다.

가능한 배포 방식:

- Vercel
- Netlify
- GitHub Pages
- Cloudflare Pages
- Firebase Hosting
- 일반 HTTPS 정적 웹 서버

---

## GitHub Pages 배포 예시

1. 저장소 루트에 `index.html`과 `README.md`를 둡니다.
2. GitHub 저장소의 **Settings → Pages**로 이동합니다.
3. Source를 `Deploy from a branch`로 설정합니다.
4. Branch를 `main` / root로 선택합니다.
5. 배포 URL에서 카메라 권한과 AI 온기 모델 로딩을 테스트합니다.

---

## Vercel 배포 예시

1. 프로젝트 폴더에 `index.html`과 `README.md`를 둡니다.
2. Vercel에서 새 프로젝트를 생성합니다.
3. 별도 빌드 명령 없이 정적 사이트로 배포합니다.
4. 배포 후 `https://...vercel.app` 주소에서 카메라 모드를 테스트합니다.

## UI/UX 메모

- 메인 화면은 단순하게 유지합니다.
- 동물 선택은 탐험 모드와 라이브 카메라 모드 안에서만 표시합니다.
- 동물 선택 탭은 한 줄 가로 스크롤 탭으로 구성합니다.
- FPS, AI confidence 같은 개발자 정보는 기본 화면에 표시하지 않습니다.
- 카메라 권한을 정상적으로 받은 뒤에는 불필요한 카메라 시작/샘플 버튼을 숨깁니다.
- 카메라 설명 문구는 일정 시간이 지나면 자동으로 사라져 체험 화면을 가리지 않게 합니다.
- 전체화면에서는 탐험 모드와 카메라 모드가 상하 중앙에 균형 있게 배치되도록 구성합니다.

## 문제 해결

### 카메라가 켜지지 않음

- HTTPS 주소에서 열었는지 확인합니다.
- 브라우저 카메라 권한을 허용했는지 확인합니다.
- 다른 앱이 카메라를 사용 중인지 확인합니다.
- 카메라 없이 샘플 장면 보기 기능을 사용할 수 있습니다.

### AI 온기가 작동하지 않음

- 인터넷 연결을 확인합니다.
- TensorFlow.js와 COCO-SSD CDN에 접근 가능한지 확인합니다.
- AI 온기 모드는 뱀 카메라 모드에서 가장 의미 있게 동작합니다.
- AI가 감지하는 대상은 `person`, `dog`, `cat`입니다.

### 너무 느림

- 보호자 설정에서 품질을 낮춥니다.
- AI 온기 모드를 끕니다.
- 전체화면을 사용해 브라우저 UI 부담을 줄입니다.
- 오래된 모바일 기기에서는 AI 모드가 느릴 수 있습니다.

### 진동이 안 됨

- 일부 브라우저와 기기는 Vibration API를 지원하지 않습니다.
- 진동은 보너스 피드백이며 핵심 기능은 아닙니다.

## 권장 보안 헤더

정식 배포 시 가능하면 아래 헤더를 설정합니다.

```http
Referrer-Policy: no-referrer
X-Content-Type-Options: nosniff
Permissions-Policy: camera=(self), microphone=(), geolocation=(), payment=()
```

단일 HTML 파일 안에 인라인 스크립트와 인라인 스타일이 있으므로, 엄격한 CSP 적용은 별도 테스트가 필요합니다.

AI CDN을 사용하는 경우 CSP에는 아래 도메인을 허용해야 할 수 있습니다.

```text
https://cdn.jsdelivr.net
```
