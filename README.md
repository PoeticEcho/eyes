# 🐾 나노바나나 동물 시각 탐험대

**나노바나나 동물 시각 탐험대**는 아이가 동물의 감각 차이를 놀이처럼 체험하면서, 각 동물이 왜 그런 감각으로 살아가는지 배울 수 있도록 만든 어린이 과학 웹 앱입니다.

현재 권장 베타 파일은 다음입니다.

```text
Beta 0.9.12-ai-mission-beta
권장 배포 파일: index_ai_mission_beta.html → index.html 로 이름 변경
```

이 앱은 동물의 감각을 100% 재현하는 과학 장비가 아닙니다. 실제 생물학 원리를 어린이가 이해하기 쉽게 바꿔 보여주는 **교육용 시뮬레이션**입니다.

---

## 1. 이번 버전의 핵심 변화

### 1.1 동물별 생존 미션 추가

게임 화면에 **오늘의 생존 미션**이 표시됩니다. 단순히 목표물을 찾는 것이 아니라, 동물이 실제 생태에서 어떤 감각을 이용해 살아가는지 이해하도록 구성했습니다.

| 동물 | 생존 미션 |
|---|---|
| 👦 사람 | 색과 모양을 균형 있게 보고 샌드위치를 찾기 |
| 🐶 강아지 | 색보다 냄새 입자와 움직임 단서를 따라 공 찾기 |
| 🐍 뱀 | 차가운 배경 속에서 따뜻한 생쥐 찾기 |
| 🐝 벌 | 꽃의 숨은 UV 길잡이를 따라 꽃 찾기 |
| 🐛 지렁이 | 밝은 곳을 피해 촉촉한 낙엽 찾기 |
| 🐠 물고기 | 둥근 물 위 창 안에 모여 보이는 목표물 찾기 |

### 1.2 보호자 질문 추가

결과 화면의 “비밀 눈 백과사전”에 **오늘 아이에게 물어보세요** 문구가 추가되었습니다.

```text
오늘 아이에게 물어보세요:
벌은 왜 꽃 가운데의 숨은 무늬를 잘 찾을 수 있을까요?
```

아이와 보호자가 게임 후 짧게 대화할 수 있도록 설계했습니다.

### 1.3 AI 온기 모드 단순화

AI 의사 열화상은 안정성을 위해 다음 세 종류만 찾습니다.

```text
person
dog
cat
```

손, 발, 얼굴을 따로 추정하던 피부색 기반 휴리스틱은 제거했습니다. 사람·강아지·고양이처럼 모델이 직접 학습한 객체만 따뜻한 온기 덩어리로 표시합니다.

### 1.4 메인 화면 단순화

메인 화면에서 동물 선택 버튼을 숨겼습니다. 동물 선택은 게임 화면 또는 카메라 화면에서만 표시됩니다.

보호자 설정은 메인 제목 왼쪽의 **🐾 이모지 버튼**으로 들어갑니다.

- 사람 눈 ↔ 동물 눈 비교 모드
- 전체화면 토글
- 정답/오답 효과음, 진동, 파티클 피드백
- 한국어 음성 안내
- 결과 화면의 “비밀 눈 백과사전”
- 보호자 질문 카드
- 저성능 모드 및 Auto 품질 조절
- 카메라 사전 동의 모달
- 개인정보 안내

| 🐶 강아지 | 적록 구분 약화, 냄새 단서 강조 | 개가 세상을 흑백으로만 보는 것은 아님 |

| 🐠 물고기 | 스넬의 창, 어안 왜곡, 수면 경계 효과 | 스넬의 창은 물고기 눈 자체가 아니라 물과 공기 경계의 굴절 효과 |

## 4. AI 온기 모드 안내

AI 온기 모드는 카메라의 뱀 모드에서 사용할 수 있는 실험 기능입니다.

```text
카메라 프레임
→ TensorFlow.js COCO-SSD 객체 탐지
→ person / dog / cat 만 통과
→ 최대 3개까지 따뜻한 온기 덩어리로 표시
→ 나머지 배경은 차가운 파랑 계열로 표시
```

중요한 주의점:

- 일반 휴대폰 카메라는 실제 적외선 열을 직접 볼 수 없습니다.
- 이 기능은 실제 체온 측정이 아닙니다.
- AI가 사람·강아지·고양이처럼 보이는 영역을 찾아 따뜻하게 칠하는 교육용 표현입니다.
- 손, 발, 얼굴을 별도로 탐지하지 않습니다.
- AI 모델은 처음 사용할 때 인터넷을 통해 불러옵니다.
- 카메라 영상 자체는 서버로 전송하지 않고 브라우저 안에서만 처리합니다.

## 5. 기술 스택

기본 앱은 `index.html` 하나로 실행됩니다.

- HTML5
- CSS3
- Vanilla JavaScript
- Canvas 2D API
- Web Audio API
- Web Speech API
- Vibration API
- MediaDevices `getUserMedia()`
- Fullscreen API
- LocalStorage

AI 온기 모드에서만 추가로 사용합니다.

- TensorFlow.js
- COCO-SSD 모델

```text
AI를 사용하지 않는 기본 게임/카메라 필터는 외부 AI 모델 없이 동작합니다.
AI 온기 모드를 켜면 TensorFlow.js와 COCO-SSD가 CDN에서 동적으로 로드됩니다.
```

사용하지 않는 것:

- React 없음
- Babel 없음
- 외부 이미지 없음
- Base64 이미지 없음
- 서버 업로드 없음
- 로그인 없음
- 광고/분석 추적 없음

## 7. 실행 방법

### 7.1 로컬에서 열기

파일을 더블 클릭해서 열 수 있습니다.

```text
index.html
```

다만 휴대폰에서 `content://media/external/file/...` 또는 `file://...` 형태로 직접 열면 카메라, 전체화면, 외부 AI 모델 로딩이 제한될 수 있습니다.

### 7.2 로컬 서버 실행

개발 중에는 정적 서버 사용을 권장합니다.

```bash
python3 -m http.server 8080
```

브라우저에서 접속:

```text
http://localhost:8080
```

### 7.3 실제 배포

카메라 기능과 AI 모델 로딩을 안정적으로 사용하려면 HTTPS 배포를 권장합니다.

가능한 배포 방식:

- Vercel
- Netlify
- GitHub Pages
- Cloudflare Pages
- Firebase Hosting
- 일반 HTTPS 정적 웹 서버

권장 사용자 안내 문구:


## 12. 문제 해결

### 카메라가 켜지지 않음

- HTTPS 주소에서 열었는지 확인합니다.
- 브라우저 카메라 권한을 허용했는지 확인합니다.
- 다른 앱이 카메라를 사용 중인지 확인합니다.
- 카메라 없이 샘플 장면 보기 버튼을 사용할 수 있습니다.

### AI 온기가 작동하지 않음

- 인터넷 연결을 확인합니다.
- TensorFlow.js와 COCO-SSD 모델 CDN에 접근 가능한지 확인합니다.
- AI 온기 모드는 뱀 카메라 모드에서 가장 의미 있게 동작합니다.
- AI가 감지하는 대상은 `person`, `dog`, `cat`입니다.

### 너무 느림

- 보호자 설정에서 품질을 `가볍게` 또는 `절전 모드`로 바꿉니다.
- AI 온기 모드를 끕니다.
- 전체화면을 사용해 브라우저 UI 부담을 줄입니다.
- 오래된 모바일 기기에서는 AI 모드가 느릴 수 있습니다.

### 진동이 안 됨

- 일부 브라우저와 기기는 Vibration API를 지원하지 않습니다.
- 진동은 보너스 피드백이며 핵심 기능은 아닙니다.

## 14. 권장 보안 헤더

정식 배포 시 가능하면 아래 헤더를 설정합니다.

```http
Referrer-Policy: no-referrer
X-Content-Type-Options: nosniff
Permissions-Policy: camera=(self), microphone=(), geolocation=(), payment=()
```

단일 HTML 파일 안에 인라인 스크립트와 인라인 스타일이 있으므로, 엄격한 CSP 적용은 별도 테스트가 필요합니다.

AI CDN을 사용하는 경우 CSP에는 TensorFlow.js와 모델 CDN 도메인을 허용해야 합니다.
