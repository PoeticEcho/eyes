# 🐾 나노바나나 동물 시각 탐험대

**나노바나나 동물 시각 탐험대**는 아이들이 여러 동물의 감각 세계를 놀이처럼 체험할 수 있도록 만든 단일 파일 웹 앱입니다.

현재 배포 후보 파일은 다음 버전입니다.

```text
Beta 0.9.6-beta
권장 배포 파일: index_95_fullscreen.html → index.html 로 이름 변경
```

이 앱은 실제 동물의 눈과 감각을 100% 재현하는 과학 장비가 아니라, 동물 감각의 핵심 원리를 어린이가 이해하기 쉽도록 변환한 **교육용 시뮬레이션**입니다.

---

## 1. 핵심 기능

- 사람, 강아지, 뱀, 벌, 지렁이, 물고기 시야 체험
- Canvas 기반 800×600 고정 해상도 렌더링
- 배경과 아이템을 한 캔버스에 합성한 뒤 동물별 필터 적용
- 동적 물리 엔진: 목표물과 방해물이 화면 안에서 이동 및 벽 반사
- 미션 보드: 글을 모르는 아이도 목표물을 알 수 있도록 아이콘 표시
- 카메라 모드: 휴대폰 카메라 화면에 동물 눈 필터 적용
- 사람 눈 ↔ 동물 눈 비교 모드
- 전체화면 토글
- 정답/오답 효과음, 진동, 파티클 피드백
- 한국어 음성 안내
- 결과 화면의 “비밀 눈 백과사전” 교육 카드
- 저성능 모드 및 Auto 품질 조절
- 개인정보 안내 및 카메라 사전 동의 모달

## 2. 동물별 교육 시뮬레이션

| 동물 | 앱에서 표현한 내용 | 교육적 주의점 |
|---|---|---|
| 👦 사람 | 일반 색상과 형태 기준 화면 | 사람 눈이 모든 생물의 기준은 아님 |
| 🐶 강아지 | 적록 구분 약화, 냄새 단서 강조 | 개가 세상을 흑백으로만 보는 것은 아님 |
| 🐍 뱀 | 가상 온도 지도 기반 열 감각 표현 | 모든 뱀이 열을 감지하는 것은 아니며, 실제 열 감지는 고해상도 카메라처럼 선명하지 않음 |
| 🐝 벌 | 겹눈 모자이크, UV 넥타 가이드 비유 표현 | 화면의 보라색은 진짜 자외선이 아니라 교육용 약속 색 |
| 🐛 지렁이 | 어두운 화면, 진동/습기/빛 변화 단서 표현 | 지렁이가 귀로 소리를 듣는다는 뜻이 아니라 비시각 감각을 비유한 표현 |
| 🐠 물고기 | 스넬의 창, 어안 왜곡, 수면 경계 효과 | 스넬의 창은 물고기 눈 자체가 아니라 물과 공기 경계의 굴절 효과 |

## 3. 기술 스택

외부 라이브러리 없이 `index.html` 하나에 모든 코드가 포함되어 있습니다.

- HTML5
- CSS3
- Vanilla JavaScript
- Canvas 2D API
- Web Audio API
- Web Speech API
- Vibration API
- MediaDevices `getUserMedia()`
- Fullscreen API
- LocalStorage: 사용자 설정 저장용

사용하지 않는 것:

- React 없음
- Babel 없음
- 외부 이미지 없음
- Base64 이미지 없음
- 서버 API 없음
- 광고/분석 추적 없음

## 4. 파일 구조

배포 시에는 아래처럼 단순하게 구성하면 됩니다.

```text
/

```

현재 파일명을 유지하고 싶다면 다음 파일을 배포하면 됩니다.

```text
index_95_fullscreen.html
```

일반적으로는 배포 전에 파일명을 `index.html`로 바꾸는 것을 권장합니다.

## 5. 실행 방법

### 5.1 로컬에서 바로 열기

파일을 더블 클릭해서 열 수 있습니다.

```text
index.html
```

단, 휴대폰에서 `content://media/external/file/...` 형태로 직접 열면 카메라, 전체화면, 일부 권한 기능이 제한될 수 있습니다.

### 5.2 로컬 서버로 실행하기

개발 중에는 간단한 정적 서버로 실행하는 것을 권장합니다.

```bash
python3 -m http.server 8080
```

브라우저에서 접속:

```text
http://localhost:8080
```

### 5.3 실제 배포

카메라 기능을 안정적으로 사용하려면 HTTPS 배포를 권장합니다.

가능한 배포 방식:

- GitHub Pages
- Netlify
- Vercel
- Cloudflare Pages
- Firebase Hosting
- 일반 HTTPS 정적 웹 서버

## 6. 카메라 모드 안내

카메라 모드는 휴대폰 카메라 영상을 앱 내부 캔버스에 그린 뒤, 동물별 필터를 적용합니다.

중요 안내:

- 카메라 영상은 서버로 전송하지 않습니다.
- 카메라 영상은 저장하지 않습니다.
- 로그인하지 않습니다.
- 위치 정보를 사용하지 않습니다.
- 광고 추적을 하지 않습니다.
- 앱 설정값만 LocalStorage에 저장합니다.

카메라 모드는 교육용 비유입니다.

- 휴대폰 일반 카메라는 실제 자외선을 직접 보여주지 못합니다.
- 휴대폰 일반 카메라는 실제 적외선 열화상을 직접 보여주지 못합니다.
- 벌의 UV와 뱀의 열화상은 화면 신호를 이용한 교육용 표현입니다.

## 7. 권장 배포 설정

### 7.1 HTTPS

카메라 권한 요청과 전체화면 기능은 HTTPS 환경에서 더 안정적으로 동작합니다.

권장:

```text
https://your-domain.example/
```

비권장:

```text
content://media/external/file/...
file://...
```

### 7.2 선택적 보안 헤더

정식 배포 시 서버 또는 호스팅 플랫폼에서 아래 헤더를 설정하는 것을 권장합니다.

```http
Referrer-Policy: no-referrer
X-Content-Type-Options: nosniff
Permissions-Policy: camera=(self), microphone=(), geolocation=(), payment=()
```

단일 HTML 파일 안에 인라인 스크립트와 인라인 스타일이 있으므로, 엄격한 CSP를 적용하려면 별도 테스트가 필요합니다.

단일 파일 구조를 유지하는 임시 CSP 예시는 다음과 같습니다.

```http
Content-Security-Policy: default-src 'self' 'unsafe-inline' data: blob:; media-src 'self' blob:; connect-src 'none'; object-src 'none'; base-uri 'none'; frame-ancestors 'none'
```

정식 서비스 수준에서는 인라인 스크립트를 별도 파일로 분리하고 nonce 또는 hash 기반 CSP를 적용하는 것이 더 안전합니다.

## 8. 사용 방법

### 8.1 게임 모드

1. `탐험 시작`을 누릅니다.
2. 상단 미션 보드에 표시된 목표 아이콘을 확인합니다.
3. 움직이는 목표물을 터치합니다.
4. 동물 버튼을 눌러 다른 동물의 시야로 바꿔 봅니다.
5. `👦 비교` 버튼으로 사람 눈과 동물 눈을 비교합니다.
6. 게임이 끝나면 비밀 눈 백과사전에서 오늘 배운 내용을 복습합니다.

### 8.2 카메라 모드

1. `📷 라이브 동물 눈`을 누릅니다.
2. 카메라 안내를 읽고 동의합니다.
3. 브라우저 카메라 권한을 허용합니다.
4. 동물 버튼을 눌러 주변 장면을 다른 동물 시야로 관찰합니다.
5. 카메라가 막혀 있으면 샘플 장면으로 필터를 체험할 수 있습니다.

## 9. 설정 옵션

설정 화면에서 다음을 바꿀 수 있습니다.

- 효과음 켜기/끄기
- 음성 안내 켜기/끄기
- 진동 켜기/끄기
- 큰 글씨 켜기/끄기
- 효과 줄이기 켜기/끄기
- 품질 모드 선택
  - Auto
  - High
  - Medium
  - Low
  - Safe

Auto 모드는 FPS를 관찰하면서 기기가 버거워질 경우 자동으로 품질을 낮춥니다.

---

## 10. 품질 모드

| 품질 | 용도 |
|---|---|
| Auto | 일반 권장 설정 |
| High | 성능이 좋은 기기, 더 선명한 필터 |
| Medium | 일반 모바일 권장 |
| Low | 저성능 기기 또는 카메라 필터용 |
| Safe | 프레임 저하나 발열이 있을 때 |

카메라 필터는 일반 게임 화면보다 연산량이 많기 때문에 저성능 기기에서는 Low 또는 Safe를 권장합니다.

## 14. 문제 해결

### 카메라가 켜지지 않아요

가능한 원인:

- 브라우저에서 카메라 권한을 거부함
- HTTPS가 아닌 주소에서 실행 중
- `content://` 또는 `file://`로 직접 열림
- 다른 앱이 카메라를 사용 중
- 기기 또는 브라우저가 `getUserMedia()`를 지원하지 않음

해결:

1. HTTPS 주소로 배포된 앱에서 다시 실행합니다.
2. 브라우저 설정에서 카메라 권한을 허용합니다.
3. 다른 카메라 앱을 종료합니다.
4. 그래도 안 되면 샘플 장면 모드로 사용합니다.

### 전체화면이 되지 않아요

가능한 원인:

- 파일을 직접 열어서 브라우저가 전체화면 전환을 제한함
- 브라우저가 Fullscreen API를 제한함
- 사용자의 직접 터치 이벤트가 아닌 상태에서 호출됨

해결:

1. HTTPS 배포 주소에서 실행합니다.
2. 버튼을 직접 눌러 전체화면을 켭니다.
3. 모바일 브라우저에 따라 주소창이 남을 수 있습니다.

### 진동이 안 돼요

가능한 원인:

- 기기가 Vibration API를 지원하지 않음
- 브라우저 정책상 진동이 제한됨
- 설정에서 진동이 꺼져 있음

해결:

- 설정에서 진동을 켭니다.
- 진동은 보너스 피드백이므로, 미지원 기기에서는 효과음과 파티클로 대체됩니다.

### 음성 안내가 안 나와요

가능한 원인:

- 브라우저가 Web Speech API를 제한함
- 기기에 한국어 음성이 없음
- 설정에서 음성 안내가 꺼져 있음

해결:

- 설정에서 음성 안내를 켭니다.
- 브라우저 또는 기기 설정에서 음성 기능을 확인합니다.
